# Проверка Windows 0.3.0-beta.1

21 октября 2026 года.

- Release-сборка .NET 8 и 78 тестов: успешно, без пропусков.
- Политика уведомлений: первый отказ, однократное напоминание, восстановление, независимые категории/устройства, повтор через 10 минут от анонса, несколько целей и остановка без ложного восстановления.
- События для уведомлений снимаются после фиксации транзакции; проверена независимость от последующих изменений детектора.
- Avalonia Headless/Skia: шесть страниц в обеих темах, скрытый запуск, закрытие в трей, возврат окна, пауза/возобновление, полный выход и выход до первого показа окна. Всплывашки проверены в обеих темах, очередь не заменяет уже показанное сообщение.
- Дополнительный прогон с настоящим Windows-бэкендом Avalonia и отдельной тестовой базой: создание трея, скрытый запуск, возврат, закрытие в трей, продолжение записи, пауза/возобновление, освобождение ресурсов. Команды вызваны программно.

## Ограничения

Физический клик по значку в области уведомлений Explorer и запуск после перезагрузки не проверены. Автозапуск не включался на рабочем компьютере пользователя. Уведомления собственные, без центра уведомлений Windows; режим «Не беспокоить» ими не управляет. Это пользовательское приложение, не служба; до входа в Windows оно не работает.

Android остаётся 0.2.0-beta.1; аппаратные проверки телефона, камеры, Keystore и поведения энергосбережения ещё нужны. Протокол сопряжения не изменён. Game Mode, bufferbloat и карта сети не входят в эту версию.
