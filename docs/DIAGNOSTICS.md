# Правила диагностики 0.1

В каждом цикле все результаты получают одну метку UTC начала цикла. Сопоставление выполняется только для одинаковых `DeviceId` и `Timestamp`: соседние циклы и разные устройства не смешиваются. Перед анализом данные ограничиваются выбранным периодом.

| Наблюдения одного цикла | Гипотеза |
| --- | --- |
| Нет активного адаптера со шлюзом | Проблема подключения устройства |
| Адаптер доступен; шлюз, внешний ICMP и HTTPS не прошли | Вероятная проблема между ПК и роутером; фильтрация ICMP не исключена |
| Шлюз доступен без потерь; внешние ICMP и HTTPS не прошли | Вероятная проблема на выходе в интернет; провайдер не установлен как причина |
| Внешний ICMP не прошёл, HTTPS полностью доступен | Возможное ограничение ICMP |
| Шлюз не отвечает, внешний ICMP или HTTPS доступен | Возможное ограничение ping роутером |
| DNS не прошёл, внешний ICMP доступен | Вероятная проблема разрешения имён |
| HTTPS не прошёл, ICMP и DNS доступны | Проверить конкретный сервис, TLS, прокси |

«Доступен» в корреляции означает успешный результат без частичных потерь. Если комбинаций недостаточно, вывод остаётся неопределённым. Из нескольких гипотез за период выводится наиболее частая. Достоверность ограничена 55% для менее трёх подтверждающих циклов; большее число циклов не превращает эвристику в доказательство.

События фиксируют наблюдаемые отклонения сразу. Повторы одной категории для устройства, вида проверки и цели объединяются. Следующий нормальный результат той же проверки закрывает событие. Остановка или перезапуск заканчивает наблюдение с пометкой «восстановление не подтверждено».

Результат с `IsConclusive=false` не участвует в локализации и не закрывает активное событие. Отсутствие наблюдения учитывается отдельным счётчиком. Успешность проверок не подменяет потери ICMP: средние потери шлюза и внешних IP считаются только по соответствующим партиям ping. Время HTTPS до заголовков не является сетевым RTT.

Полный и инкрементальный анализ используют один DiagnosticAccumulator. При сдвиге окна он вычитает старые циклы и добавляет новые; выборка графика не влияет на сводные показатели. JSON/CSV получают исходные строки потоком, независимо от ограничения превью.

Буфер обмена, пакеты приложений и содержимое трафика не читаются. Будущая синхронизация Android потребует сопряжения с подтверждением, шифрования, аутентификации и локальной очереди, а также учёта расхождения часов. Текущая версия не открывает входящий сетевой порт.
