# LANProof brand assets

Оригинальный знак LANProof: защитный контур и соединённые узлы сети в синем стеклянном квадрате. Логотип Apple и системные значки Apple не используются.

- `logo/lanproof-mark.svg` — основной векторный знак.
- `logo/lanproof-mark.png` — прозрачный PNG 512×512.
- `logo/lanproof-wordmark-dark.svg`, `logo/lanproof-wordmark-light.svg` — логотип с названием для двух тем.
- `icons/*.svg` — 11 векторных иконок разделов, показателей и переключения темы. Цвет задаётся через `currentColor`.
- `app/AppIcon.ico` — Windows-иконка в размерах 16, 24, 32, 48, 64, 128, 256.

Иконка встроена в exe и окно приложения. Векторные элементы интерфейса повторяют эти пути и масштабируются без растрового размытия. Исходники иконок генерируются скриптом `tools/build-assets.cjs`; установка инструмента: `npm install --prefix tools`, затем `node tools/build-assets.cjs`.

Все оригинальные изображения этой папки распространяются по MIT-лицензии проекта.
