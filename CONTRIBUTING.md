# Участие в разработке

Проверьте существующие [issues](https://github.com/MortisBTD/LANProof/issues). Для крупного изменения сначала опишите проблему и предлагаемый объём работ в issue. Небольшие исправления можно отправлять pull request сразу.

## Локальная проверка

Нужны Windows, Git и .NET SDK 8 или 9.

```powershell
dotnet restore LANProof.sln
dotnet build LANProof.sln -c Release
dotnet test LANProof.sln -c Release
```

Для изменений интерфейса перегенерируйте кадры обеих тем:

```powershell
$env:LANPROOF_UI_QA_DIR="$PWD\work\ui-preview"
dotnet test LANProof.sln -c Release --filter FullyQualifiedName~ThemeUiTests
```

Headless-кадры не проверяют системные эффекты Windows и файловые диалоги. Укажите, что проверялось вручную.

## Pull request

- Один PR решает одну понятную задачу.
- Опишите изменение, причину и фактически выполненные проверки.
- Для изменений измерений и диагностики добавьте регрессионную проверку с воспроизводимыми данными.
- Для интерфейса приложите кадры обеих тем; подпишите синтетические данные.
- Сохраняйте различие между отказом, частичными потерями и отсутствием результата.
- Не добавляйте базы пользователей, персональные отчёты, токены и папки `data/`, `work/`, `publish/`, `bin/`, `obj/`.

Перед публикацией сетевых отчётов удаляйте персональные сведения. Для проблем безопасности используйте [SECURITY.md](SECURITY.md).
